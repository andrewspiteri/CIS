# `cis ui-direction validate`

```text
cis ui-direction validate [--workspace <path>] [--format <human|json|agent>]
```

Validates canonical identity, required sections, all twelve question links, absence of placeholders,
solution/questionnaire currency, design-guideline and UI-framework provenance, and approval digest.
A structurally valid current Review Required document reports Ready for Approval.
